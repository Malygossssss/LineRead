# Windows 桌面单行阅读器

一个连接微信读书网页版的 PySide6 悬浮阅读器。窗口无边框、始终置顶，移入鼠标时显示，移开后降到 5% 透明度。

## 安装与启动

建议使用 Python 3.10 或更高版本：

```powershell
pip install -r requirements.txt
python -m playwright install chromium
python main.py
```

如果 `python` 指向不兼容的 MSYS2 解释器，可改用 Windows Python Launcher（本机已用 3.13 验证）：

```powershell
py -3.13 -m pip install -r requirements.txt
py -3.13 -m playwright install chromium
py -3.13 main.py
```

以上命令都应在项目虚拟环境中执行；不要为 LineRead 修改全局 Python。每次启动都会直接连接微信读书，不再读取 TXT 来源或弹出文件选择框。悬浮窗会立即出现，并根据浏览器状态显示“正在连接微信读书…”“等待登录…”“等待选书…”或“文本渲染中…”。

## 操作

- 滚轮向下：下一条
- 滚轮向上：上一条
- `Ctrl + 滚轮`：字号增减，范围 10–40（默认绑定，可修改）
- `Shift + 滚轮`：鼠标移入时的透明度增减，范围 0.2–1.0（默认绑定，可修改）
- 按住鼠标左键拖动：移动悬浮窗
- 鼠标右键：打开书籍、搜索/选择章节、阅读详情和设置菜单
- `Alt + F4`：关闭并保存窗口设置

窗口拖动结束及下次启动时会自动限制在当前显示器的可用区域内，不会藏入任务栏或屏幕外。LineRead 同时只允许一个实例运行；重复启动会唤醒并显示已经运行的窗口。

设置页可以查看完整操作说明、直接修改字号与可见透明度，并为“调整字号”和“调整透明度”分别选择 `Ctrl`、`Shift` 或 `Alt` + 滚轮。两个操作不能使用相同修饰键；保存后立即生效。

## 微信读书

LineRead 使用 Playwright 控制微信读书公开网页版，并通过页面自带布局控件保持横向翻页模式。程序把微信读书当前显示的单页或双页画面统一视作“当前页面”，只读取 `.renderTargetContainer` 中已经渲染的 DOM、定位文字或 Canvas，不再跳到章节顶部扫描整章。Canvas 像素直接从页面内存读取，并使用本地 RapidOCR 按视觉顺序还原文字行；页面仍提供语义文本时，还会在保持视觉行边界的前提下校正 OCR 误字。低置信度文字行会放大后重试，并且只在重试结果置信度更高时替换原文。它不读取浏览器缓存、不拦截私有接口，也不尝试解密微信读书数据，Canvas 图像和正文不会上传到 OCR 服务。

首次连接时会打开独立的 Chromium 窗口。LineRead 会自动检查登录和选书状态：尚未登录时保持“等待登录…”，登录后尚未进入书籍时显示“等待选书…”，进入阅读页后自动开始提取正文并显示“文本渲染中…”。正文准备完成后，状态文字会替换为微信读书当前页面的第一行，全程不需要确认提示框。LineRead 不保存或恢复微信读书的书籍、章节、页码和行号，而以微信读书自身的跨设备进度为准。页内逐行阅读不会操作网页；当前页准备完成后，程序会在后台临时翻到下一页完成提取和 OCR，再返回当前页。越过末行时若预取已经完成会直接显示缓存页，越过首行时也会优先复用最近读过的页面；快速翻页超过预取速度或预取失败时自动回退到原有异步加载流程。页面快照最多保留五个且仅存在于本次运行的内存中，相同 Canvas 像素的 OCR 结果也会短期复用。首次 Canvas OCR 需要加载本地模型，通常比后续页面慢。浏览器必须在 LineRead 运行期间保持开启，但可以置于后台或最小化。

右键菜单为“打开微信读书”“切换书籍”“选择章节…”“上一章”“下一章”“阅读详情”“设置”“退出”。“选择章节…”会打开可搜索的完整目录并定位当前章。章节切换和未命中缓存的按需翻页会立即在悬浮窗显示“文本渲染中…”，OCR 在后台完成后再替换正文；缓存命中的翻页直接衔接，不显示等待文字。失败时悬浮窗会恢复切换前的页面内容和行。章节切换不冒险在同一浏览器标签中预先跳章，以免丢失当前章的精确页位；切换完成后会立即开始准备新章的下一页。切换书籍时，先在恢复的浏览器窗口中手动进入新书，再点击提示框“确定”。每次启动、重新载入或切换书籍后，LineRead 都从微信读书当前页面第一行开始。“阅读详情”显示“当前章节”和“当前页面进度”，不显示无法从公开页面稳定读取的页码或章节总行数。

正文单位与来源行一一对齐：Canvas OCR 的每个视觉文字行显示一次，TXT 的每个非空物理行显示一次，不再根据标点或固定字数进行二次切分。

Playwright 的持久浏览器配置默认保存在 `%LOCALAPPDATA%\LineRead\WeReadProfile`，用于尽量保留登录状态。可用 `LINEREAD_WEREAD_PROFILE` 环境变量覆盖路径。微信读书网页结构更新后，章节选择器可能需要同步调整；此时 LineRead 会显示错误，不会改写已有阅读位置。

在 Windows 安全策略拒绝启动 Playwright 下载的有界面 Chromium（`spawn UNKNOWN`），或其可执行文件暂时不存在时，LineRead 会自动回退到本机安装的 Google Chrome，并继续使用上述独立配置目录；不会复用或修改日常 Chrome 用户配置。其他启动错误不会被回退逻辑掩盖，弹窗会显示真实底层原因。

窗口位置、宽度、字号、可见透明度和滚轮快捷配置保存在项目目录下的 `config.json`。该文件不再记录微信读书的书籍、章节、URL 或行号；旧版留下的微信读书进度字段会在下次保存时移除。该文件仅供本机使用且已被 Git 忽略，仓库中的 `config.example.json` 提供默认配置示例。设置页仍只负责字体、字号、透明度和快捷操作，不包含切书或章节切换。

## 项目结构

- `main.py`：应用启动、微信读书连接和错误提示
- `reader_window.py`：悬浮窗显示与桌面交互
- `chapter_selection_dialog.py`：当前书籍的可搜索章节选择窗口
- `settings_dialog.py`：右键设置页与快捷配置校验
- `text_parser.py`：正文清理与来源行边界保留
- `weread_source.py`：Playwright 持久会话、目录章节控制、DOM/Canvas OCR 提取与章节缓存
- `reading_details_dialog.py`：当前来源、书籍/章节和行号的只读详情
- `config.py`：JSON 配置读取、校验和原子保存
- `tests/`：解析、配置和窗口行为测试
